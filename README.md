# StitchDuck Website

Official website for [StitchDuck (绣鸭)](https://stitchduckapp.com), a cross-stitch
pattern maker for iPhone, iPad and Mac.

Static HTML/CSS in the app's eight languages — English, 简体中文, 繁體中文, Deutsch,
Español, Français, 日本語 and Русский — each at its own URL. The published pages
are generated from the multilingual sources in `_src/pages/`; after editing one,
rebuild with:

    python3 _src/build.py
